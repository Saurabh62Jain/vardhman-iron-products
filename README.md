## 🚀 लाइव वेबसाइट देखने के तरीके (Deployment on GitHub Pages)

### GitHub Pages पर लाइव डिप्लॉयमेंट:
1. इस रिपॉजिटरी की **Settings** > **Pages** पर जाएं।
2. **Build and deployment** में **Source** को **Deploy from a branch** चुनें।
3. **Branch** में `main` (या `master`) शाखा और `/ (root)` फ़ोल्डर चुनकर **Save** पर क्लिक करें।
4. 1-2 मिनट में आपकी वेबसाइट लाइव यूआरएल पर उपलब्ध होगी:  
   `https://<your-username>.github.io/<repository-name>/`
